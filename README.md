# ROBOTDOLLY DarkRide Server

Experimental GitHub Actions build of a Linux amd64 Docker server image from Caitlyn Meeks' official DarkRide `v1.0.0` source, using Madders' `linux-server-docker` packaging scripts.

This repository contains a build workflow, not a copy of the upstream source. No automatic deployment. **Do not replace the live Synology server or mount its existing world folder while testing.**

Source: https://github.com/caitlynmeeks/darkride-interface/tree/v1.0.0
Docker recipe: https://github.com/Madders/darkride-interface/tree/linux-server-docker/docker/server
